# Data and model provenance

The included tree calibration and geological material tables retain their scientific
citations, evidence classes, uncertainty and model-assumption labels. Many numeric
intervals are project priors, not extracted measurements or validated confidence
intervals. No referenced paper or reference photograph is bundled.

The redbed optics model contains an RGB value derived from the USGS Spectral Library
Version 7 hematite record identified by title and SHA256 in its JSON metadata. The
source spectrum is not bundled. USGS identifies that data release as CC0 1.0:
https://www.usgs.gov/data/usgs-spectral-library-version-7-data
Citation: Kokaly and others (2017), USGS Spectral Library Version 7 Data,
https://doi.org/10.5066/F7RR1WDJ. Derived RGB is a model input, not full spectral
transport or a claim of a measured appearance for every generated rock.

Bibliographic references to mineralogy, geology, botany and optics are retained
for attribution and to explain assumptions. Rights in those publications remain
with their holders. The tree ledger explicitly distinguishes reported transcriptions
from independently verified measurements; release preparation does not promote
unverified values into verified observations.

Game meshes, texture packs, downloaded reference photographs, engine project content
and precomputed large worlds are excluded. Newly generated demo outputs come from
the included algorithms and recipes, with their declared approximation limits.
